# Capital Management

## Smart Capital Tiers + Auto-Sweep

---

## 1. Capital Tiers

The Capital Tier Manager dynamically detects the current capital level
and adjusts trading slots, universe selection, and allocation strategy.

### Default Tiers

| Level | Balance | Slots | Active Capital | Universe |
|-------|---------|-------|---------------|----------|
| LEVEL_1 (Small) | ≤ $5,000 | 2 | 100% of balance | All qualified Spot (TIER_A/B/C) |
| LEVEL_2 (Medium) | $5,001–$100,000 | 5 | 100% of balance | Diversified qualified Spot |
| LEVEL_3 (Large) | $100,001–$5,000,000 | 10 | 100% of balance | TIER_A + TIER_B prioritized |
| LEVEL_4 (Cap) | > $5,000,000 | 20 | Capped at $5M | Deep-liquidity only (A+B) |

All thresholds are **configurable** via `CapitalTierConfig`.

### Key Principle

**Increasing account equity → more slots, NOT larger single positions.**
The system scales horizontally across qualified opportunities.

---

## 2. Asset Quality Filter

Assets qualify based on **measurable criteria** — NOT social popularity,
market-cap rank, or coin-name lists.

### Quality Criteria (all must pass)

| Check | TIER_A | TIER_B | TIER_C |
|-------|--------|--------|--------|
| 24h Volume | ≥ $100M | ≥ $25M | ≥ $1M |
| Spread | ≤ 0.05% | ≤ 0.20% | ≤ 2.00% |
| Depth at 10bps | ≥ $500K | ≥ $100K | ≥ $10K |
| Data Freshness | ≤ 60s | ≤ 60s | ≤ 60s |
| Market Age | ≥ 30d | ≥ 30d | ≥ 30d |
| Daily Trades | ≥ 100 | ≥ 100 | ≥ 100 |
| Liquidity Score | ≥ 0.20 | ≥ 0.20 | ≥ 0.20 |

### Classification

- **TIER_A**: BTC, ETH, and other deep-liquidity assets
- **TIER_B**: SOL, XRP, BNB, and other highly liquid altcoins
- **TIER_C**: Qualified medium-liquidity altcoins
- **TIER_D**: Rejected — insufficient liquidity/data/volume

**No asset name is hard-coded.** BTC itself must pass liquidity checks
(and always does). If a "major" asset becomes illiquid, it drops tiers.

---

## 3. Slot Allocation by Tier

The Capital Tier Manager distributes slots across quality tiers:

1. Fill TIER_A slots first (deepest liquidity)
2. Fill TIER_B slots next
3. Fill TIER_C slots last (capped at 40% of total slots)

Level 3 and 4 exclude TIER_C entirely — they focus on deep liquidity.

## 4. Auto-Sweep

### Status: SIMULATION ONLY. No real withdrawals.

When total_balance exceeds the active capital cap ($5M by default):

```
excess = total_balance - active_capital_cap
daily_profit = max(0, daily_realized_profit)
sweep_eligible = min(excess, daily_profit)

# Subtract reserved capital (open positions + orders)
# Apply minimum sweep threshold
```

### Rules

- ❌ Never sweep unrealized profit
- ❌ Never sweep borrowed funds
- ❌ Never sweep capital needed for open positions
- ❌ Never auto-execute (approval_required = True)
- ✅ Only realized daily profit above the cap

### Destination Types (abstractions only)
- CASH_RESERVE
- SECURE_WALLET
- EXTERNAL_TREASURY
- GOLD_ALLOCATION
- FX_RESERVE
- MANUAL_REVIEW (default)

### Future Live Sweep Requirements
- Explicit separate configuration
- Whitelist destination addresses
- Additional approval gate
- Separate API permissions
- Full audit log
- Risk checks

## 6. Configuration

All parameters in `CapitalTierConfig`, `QualityFilterConfig`, and `SweepPolicyConfig`.

Environment overrides prefixed with `CAPITAL_`, `QUALITY_`, `SWEEP_` (future).

---

## 7. Integration

```
Account Balance → CapitalTierManager.determine_tier()
    → sets target slots, allowed tiers
    → AssetQualityFilter filters universe
    → CapitalAllocator distributes within tier constraints
    → SweepEngine checks for excess capital
    → generate_daily_report() produces summary
```
